# 🎵 Musiczzz - Music Player

A modern and responsive music player website built using **HTML, CSS, and JavaScript**.

The project provides a simple and attractive interface for playing local music files with controls such as play, pause, next, previous, shuffle, repeat, volume control, progress tracking, search, and liked songs.

## ✨ Features

- ▶️ Play and pause songs
- ⏮️ Previous and next song controls
- 🔀 Shuffle songs
- 🔁 Repeat songs
- 🔊 Volume control
- 📊 Music progress bar
- ❤️ Like songs
- 🔍 Search songs and artists
- 📱 Responsive design
- 🎨 Modern dark-themed UI
- 🎵 Local MP3 music support
- ⚡ Automatic next-song playback

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- HTML5 Audio API
